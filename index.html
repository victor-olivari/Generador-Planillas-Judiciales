Configuración — Proxy Automático (Cloudflare Worker)
Para consultar tasas automáticamente del PJ Chaco es necesario configurar un Cloudflare Worker gratuito que actúa como proxy. Se configura una sola vez y queda guardado.
1 Crear el Worker en Cloudflare (gratis, 2 minutos)
  1. Ir a workers.cloudflare.com y crear cuenta gratuita (o iniciar sesión)
  2. Hacer clic en "Create a Worker"
  3. Borrar todo el código de ejemplo y pegar el código de abajo
  4. Hacer clic en "Save and Deploy"
